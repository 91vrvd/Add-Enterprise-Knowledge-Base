# 企业知识库页面 / Enterprise Knowledge Hub

一个静态前端演示页面，展示知识分类、知识图谱、检索界面和治理流程。页面里的指标、日志与检索结果是示例数据，没有连接真实企业知识库。

打开 [演示页面](./Enterprise-Knowledge-Hub-Website/index.html) 可以查看界面。无需安装依赖。

**English:** A static front-end demo of an enterprise knowledge hub. Metrics, activity logs, and search results are sample data; no company data source is connected.
